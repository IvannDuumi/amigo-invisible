# 🎁 Amigo Invisible

App web (100% estática) para organizar un Amigo Invisible y avisarle a cada participante por WhatsApp.

## Funciones
- Datos del evento: nombre, fecha, lugar, presupuesto mínimo/máximo y organizador.
- Participantes con WhatsApp opcional.
- Exclusiones: parejas (o quien sea) que no se pueden tocar entre sí.
- Opción de **una sola ronda** (todos forman una única cadena).
- Indicaciones/reglas editables.
- Resultados ocultos para que el organizador también juegue.
- Envío por WhatsApp con **link secreto** (la persona abre el link y "desenvuelve" su regalo) o con el nombre directo.
- **Cartel** en imagen (PNG) para compartir por WhatsApp desde el celular o descargar.
- Los datos se guardan sólo en el navegador (localStorage).
